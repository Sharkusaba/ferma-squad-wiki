# Первые шаги

После одобрения заявки:

## 1. Проверьте игровой ник

```
/nick ваш_ник
```

Если ник уже был указан в анкете при регистрации, бот может подтянуть его автоматически — проверьте профиль:

```
/profile
```

## 2. Сделайте первый чек-ин

Раз в 7 дней вы можете отмечаться и получать Гос. рейтинг (ГР):

```
/checkin
```

Чек-ин также нужен, чтобы ваш статус оставался «Активен», а не «Резерв» — подробнее в разделе [Гос. рейтинг](../gos-reiting/kak-nachislyaetsya).

## 3. Посмотрите структуру сквада

Узнайте, какие есть службы и министерства, и какая у них иерархия — см. [Структура сквада](../struktura/ministerstva).

## 4. Следите за госзаказами

Госзаказы публикуются на форуме и дают возможность заработать Гос. рейтинг за выполненные задачи — см. [Госзаказы](../gos-reiting/gosZakazy).

## 5. Если что-то не понятно

Загляните в раздел [Команды бота](../bot/komandy) или [Частые вопросы](../bot/faq), либо обратитесь к сотрудникам служб.
