# Вики сквада Ferma Squad

Статический сайт на [VitePress](https://vitepress.dev). Весь контент — обычные `.md` файлы в папке `docs/`, редактировать можно прямо в GitHub или любым текстовым редактором.

## Структура проекта

```
docs/
  .vitepress/
    config.mts        ← навигация, боковое меню, настройки сайта
  public/
    favicon.svg        ← иконка сайта
  index.md              ← главная страница
  novichkam/            ← раздел «Новичкам»
    registraciya.md
    pervye-shagi.md
  struktura/             ← раздел «Структура сквада»
    ministerstva.md
    ierarhiya.md
  gos-reiting/           ← раздел «Гос. рейтинг»
    kak-nachislyaetsya.md
    gosZakazy.md
  bot/                   ← раздел «Пользование ботом»
    komandy.md
    faq.md
```

## Как добавить новую страницу

1. Создайте `.md` файл в нужной папке раздела (или новой папке для нового раздела).
2. В начале файла можно (не обязательно) добавить заголовок первой строкой `# Название страницы`.
3. Откройте `docs/.vitepress/config.mts` и добавьте ссылку на новую страницу в `sidebar` (в нужный раздел) и, если нужно, в `nav`.
4. Сохраните — на Cloudflare Pages сайт пересоберётся автоматически при пуше в GitHub (см. ниже).

## Как добавить новый раздел

1. Создайте новую папку в `docs/`, например `docs/pravila/`.
2. Добавьте в неё `.md` файлы.
3. В `docs/.vitepress/config.mts`:
   - добавьте пункт в `nav`, указывающий на первую страницу раздела;
   - добавьте новый ключ в `sidebar` вида `"/pravila/": [...]` по образцу существующих разделов.

## Локальный просмотр (по желанию)

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

## Деплой на Cloudflare Pages

1. Залейте этот проект в репозиторий на GitHub (или GitLab).
2. В Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**, выберите репозиторий.
3. Настройки сборки:
   - **Framework preset**: VitePress (если нет в списке — настройте вручную, см. ниже)
   - **Build command**: `npm run build`
   - **Build output directory**: `docs/.vitepress/dist`
4. Нажмите **Save and Deploy**.

После этого при каждом пуше в ветку (обычно `main`) Cloudflare Pages будет пересобирать и обновлять сайт автоматически — отдельно ничего собирать не нужно.

### Редактирование прямо на GitHub

Самый простой способ редактировать вики без установки чего-либо на компьютер:

1. Откройте нужный `.md` файл в репозитории на github.com.
2. Нажмите иконку карандаша («Edit this file»).
3. Внесите правки, внизу нажмите **Commit changes**.
4. Cloudflare Pages автоматически пересоберёт сайт за 1–2 минуты.

Ссылка «Редактировать эту страницу на GitHub» внизу каждой страницы ведёт туда же — не забудьте прописать свой репозиторий в `editLink.pattern` в `config.mts`.

## Markdown-возможности VitePress

Кроме обычного Markdown доступны блоки-подсказки:

```md
::: tip
Полезный совет
:::

::: warning
Предупреждение или место, которое нужно уточнить/дополнить
:::

::: danger
Важное предупреждение
:::
```

Таблицы, списки, ссылки между страницами (`[текст](../papka/fajl)`) — обычный Markdown.
